# Offline test data

These fixtures exercise contracts and deterministic selection, not current market
claims. Export fixtures are reduced test documents, not deployable daily briefs.
The dated headline fixture combines reduced historical metadata with synthetic
controls; timestamps, publisher identities and example official URLs are inputs
for testing provenance logic, not verified current evidence. No fixture URL should
be fetched by an offline test. Directional wording inside an attributed source
headline is an input under test, not this project's recommendation.

Do not redistribute production source bodies or personal research artifacts as
fixtures. Use synthetic data for new cases and separately review source rights
before publishing samples.
