## Final integration decisions

The combined store persists clinical definition dependencies separately and binds
them to event correction state. Packets disclose definition evidence only through
its own rights. Merged filings rebuild numeric and amount projections before
validation. Statement-origin units remain explicit and unassessed for independence.

Collector query plans are stable and inspected before transport; observed poll
windows use the previous actual acquisition clock only for the same route, family,
query, policy and implementation with matching raw/native traversal evidence.
Source publication time is never substituted as that clock. Acquired inventory
counts explicitly identify their basis and preserve any separately reported
source totals.

Public main-CLI dispatch now reaches prospective, vertical, expansion and operating
commands. Planning branches remain network-free. Source calls made through the
measurement hook validate the frozen context but cannot change membership or
manufacture request counts. Rights-safe projections cover historical publication
inspection, current briefs, history, lead queues and ingest diagnostics.

All three dependent gates validate typed current records, exact protocol/candidate
scope and an explicit aligned operating window. Complete source reports, source
permissions, useful-brief assessments, all feedback including negative feedback,
and monetary inventories remain separate prerequisites. The implementation
returns readiness for human review only. It never changes activation state.
